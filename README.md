# Apollo H-1 Holiday Ornament

![Apollo Automation H-1](H-1.JPG)

**Key Features of the H-1:**

- USB-C or battery powered ornament with 22 controllable RGB LEDs and a buzzer to play holiday tunes
- Comes preloaded with 3 holiday tunes and 3 RGB LED patterns, played from the single button on the back (one press, two presses, or long press)
- Comes flashed with basic firmware but can be flashed with our smart firmware to connect and control from Home Assistant
- Could also be used as a bluetooth proxy or bluetooth tracker
- Features an ESP32-C3 processor

**100% of profits donated** to a local charity in Lexington, KY.
